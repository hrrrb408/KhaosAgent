## Decision criteria

A: cancellation is task/connection-bound and must preserve real Kernel results across actual Launcher UI and XPC. B11 additionally needs a signed nonzero command that commits, so return code cannot be mistaken for rollback. B33 and B35–B36 require signed pre-replacement/Runner-death records; B34 does not cover those earlier stages.

B: existing exact-path, symlink, hardlink, APFS alias and race probes already exercise the real shared Kernel/OS validator. A small signed request can show wiring, but does not reproduce every race. Reuse is recommended only for that shared invariant after owner reviews identical production Kernel bytes, fixed Runner source, canonical passing tests, signed scope/digest binding and the explicit remaining entry risks. No permission/scope rule is changed here. Owner may require full signed repetition instead.

C: B16 was an actual validator coverage gap, because the Runner was stopped by OS before deleting. The new test injects the private deletion directly and invokes the real isolated Kernel committer through its existing bounded commit frame. It does not claim the Runner could perform that deletion or count as signed UI evidence.
