## Reuse decision

Reuse the review patterns and state semantics, not source code or frameworks. Pi's general patch/diff behavior and file queue are larger than Candidate B needs and rely on direct file access. Khaos needs a small replacement-block preview derived from the exact approved argv, a complete-details view, and Kernel-confirmed post-run results. No new third-party dependency is justified. The source review is complete; the Khaos integration remains blocked on trusted UI review and signed acceptance.
