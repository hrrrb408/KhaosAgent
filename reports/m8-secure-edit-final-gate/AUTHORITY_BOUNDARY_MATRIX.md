## Reuse decision

The real L3 Runner and Kernel tests support the same snapshot, complete-changeset, scope, and commit implementation. Where Candidate B's fixed script, exact scopes, and same Kernel commit path are exercised, those records are proposed as reusable evidence for the shared Kernel invariant. They do not satisfy an original L4 requirement whose remaining risk is Launcher/XPC entry, UI review, cancellation-to-Task-Record mapping, or signed product binding. No independent reviewer approved changing the inherited Gate A standard.
